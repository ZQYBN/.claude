# 后端规则

> 适用：Spring Boot 3 + JPA + MySQL

## API 规范

- 所有接口返回值必须包装在统一结构 `{ code, message, data }` 中
- 禁止直接返回实体对象或原始类型（即禁止返回裸数据）

## 错误处理

- 禁止捕获异常后不进行任何处理（包括：不记录日志、不向上层抛出、不返回错误响应）。禁止使用空的 catch 块
- 每条错误日志必须包含：发生时间、触发操作的上下文、异常堆栈。日志级别须与实际严重程度一致

## 数据库

- 实现前必须确认数据库实际 schema（包括：字段是否可为空、索引定义、状态字段的合法取值）
- 禁止仅依据 ORM 实体类推断数据结构
- 禁止自动执行破坏性 SQL 语句（DROP TABLE、TRUNCATE、无 WHERE 条件的 DELETE 等）
