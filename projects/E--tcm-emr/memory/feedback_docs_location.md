项目相关文档（PRD、设计文档、TODO、技术方案、spec 等）默认写入 `E:\tcm-emr\tcm-emr-app\docs` 目录，除非用户明确指定了其他位置。

**Why:** 用户要求统一文档位置，避免文档散落在项目根目录或其他位置。

**How to apply:** 当需要创建 `.md` 文档、spec、plan 等文件时，默认路径应为 `E:\tcm-emr\tcm-emr-app\docs/`。如果用户指定了其他路径，以用户指定为准。
